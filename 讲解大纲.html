一、系统简介 overview

核心功能

读取 / 维护 Excel 台账，标准品快速入库，关联标准品证书，配置储备液、应用液、工作液，自动格式修约，自编号自动生成，配置记录一键导出，标液标签一键打印，标液核查记录导出。

二、登录流程 login

2.1 登录步骤

  1. 打开登录页，输入 LIMS 账号、密码 和 验证码
  2. 验证码图片可点击刷新
  3. 密码框右侧有 👁/🙈 显示/隐藏切换按钮
  4. 点击登录 → 系统验证身份 → 成功后跳转至有机标准品管理页
⚠ 注意：
• 账号、密码、验证码均为必填

三、有机标准品管理页 organic-std

3.1 操作流程（按使用顺序）

① 加载数据

页面打开时自动从配置的 Excel 文件加载台账。未配置路径时，先到「设置」配置 Excel 路径。

② 查询标准品

  1. 在查询区输入 名称 / CAS号 / 实验室编号（模糊匹配）
  2. 按需选择筛选条件：
    • 组别
    • 过期状态：全部 / 仅过期 / 仅有效 / 即将过期（2 个月内）
    • 使用情况：未开封 / 开封
  3. 查看结果：灰色背景行 = 已过期标准品

③ 新增标准品

  1. 点击顶部「新增」
  2. 填写 必填字段：组别（*）、标品名称（*）、CAS号（*）
  3. （建议）先输入实验室编号查询 LIMS，结果自动回填表单
  4. 保存 → 自动同步写入 Excel，同时更新使用情况

④ 编辑标准品

  1. 点击操作列「编辑」按钮
  2. 修改信息
  3. 保存 → 同步 Excel
  4. 若修改了浓度单位：系统自动检测变更，确认后同步回写 LIMS

⑤ 删除标准品

  1. 点击操作列「删除」
  2. 在二次确认弹窗中确认（防止误删）

⑥ 查看证书

  1. 点击 📄 图标
  2. 系统在证书目录下搜索 PDF：直接文件名 → 年份文件夹 → 年份+分类文件夹（消费品、轻工、FCM、MD、日化等）

⑦ 设置 / 配置

  1. 点击「设置」
  2. 配置 Excel 文件路径（UNC 网络路径）
  3. 配置 证书文件夹路径（UNC 网络路径）
  4. 保存 → 自动重新加载数据
管理员（崔艳梅）可在设置中额外管理各用户的独立路径配置。

四、标准物质配置页 solution-config

4.1 三个标签页总览

标签页功能配制方向
A-B从标准品配制储备液A → B
BC-BCD从已配溶液继续配制B → B/C/D
D工作液管理查询 / 核查 / 导出

4.2 A-B 操作流程：标准品 → 储备液

  1. 搜索标准品：输入实验室编号 / 名称 / CAS号，可按使用部门筛选
  2. 选择标准品：勾选需要配制的标准品
  3. 填写配制参数：配置日期✅、温度✅、湿度✅、配置设备（g 时必填）、溶剂/介质、保存条件、有效期自动计算
  4. 确认领用并保存
  5. 导出配制记录（Word）

批量应用：点击 "↓" 按钮可将溶剂、保存条件、有效期批量应用到所有行。

导出规则：单位为 g 或浓度单位含 % 的记录合并为一份 Word；其余类型（如 μg/mL）逐条单独导出。

4.3 BC-BCD 操作流程：储备液 → 应用液 / 工作液

  1. 查询已配溶液，选择源溶液
  2. 选择配制类型：储备液(B) / 应用液(C) / 工作液(D)
  3. 填写参数：混合液名称✅、自编号✅、配置日期✅、有效期至✅、温度✅、湿度✅、保存条件✅、（类型为多源时必填）
  4. 配置稀释方案 → 若为工作液(D)，详见 §4.4
  5. 确认领用并保存
  6. 导出记录（单源 / 混合 / 合并）→ 打印标签

4.4 工作液(D) 操作流程：稀释配置

  1. 生成稀释点：支持 1~12 个浓度点，点击「生成稀释点」按钮后渲染表格
  2. 设置三个开关（见下方操作要点）
  3. 录入数据：从 .D 数据文件导入 / 手动录入 / Excel 粘贴
  4. 保存，自编号自动生成（浓度范围 [min-max]，手动修改后切换为手动模式）
三个开关：
① 逐级稀释——开启后 N 点源浓度 = N-1 点结果浓度
② 紫外——名称含"甲醛"或"六价铬"时自动勾选
③ 基体——手动开启，出现基体输入框，自编号追加 -{基体名} 后缀

4.5 标签打印操作流程

入口

打印步骤

  1. 点击「打印标签」→ 系统调用 /api/lims/print_label 生成标签图片
  2. 弹出标签预览弹窗，逐个展示标签图片
    • 工作液每个稀释点各显示一张，标注"稀释点 N: 浓度"
    • B/C 类型显示一张
  3. 用户确认预览内容无误后，点击「确认打印」
  4. 系统逐张调用 /api/lims/do_print 发送到标签打印机
    • 多个标签之间自动间隔 1 秒，避免打印机队列拥堵
  5. 打印完成后按钮变为 ✓ "打印成功"
⚠ 注意：
• 打印前请确认标签打印机已连接并开机
• 打印服务依赖 npm start 启动的本地打印服务，若服务未启动会报错
• 标签字体使用 Windows 系统字体（微软雅黑/宋体），确保系统字体完整
• 预览时可检查编号和浓度是否正确，确认后再打印

4.7 标液核查操作流程

核查用于比对新旧两批工作液的浓度一致性，判断旧标液是否仍可继续使用。

  1. 进入 D 标签页，勾选恰好 2 条 D 型工作液记录
  2. 点击「核查」按钮
  3. 选择核查模式：新验旧 / 旧验新（见下方要点）
  4. 选择偏差阈值：5% 或 10%（核查方法固定为"新旧标准曲线比对"）
  5. 勾选浓度点（标准物质信息由系统自动追溯溯源链 D → C → B → A 填充）
  6. 录入实测数据：.D 文件（推荐）/ 手动录入 / Excel 粘贴
  7. 自动匹配物质，匹配失败时下拉框手动选择 LIMS 名称后回填理论值
  8. 查看核查结果：偏差 = |理论值 - 实测值| / (理论值 + 实测值) × 100；超标行变红
  9. 导出核查记录（有 .D 数据 → PDF；无 → Word）

核查模式与判定（操作要点）

模式含义被核查对象核查对象
新验旧新标液作标准曲线测旧标液新标液（固定显示）旧标液（勾选浓度点）
旧验新旧标液作标准曲线测新标液旧标液（勾选浓度点）新标液（固定显示）

相对偏差 = |理论值 - 实测值| / (理论值 + 实测值) × 100

  • 偏差 ≤ 阈值 → 行正常
  • 偏差 > 阈值 → 行变红色，表示不合格
  • 核查结论自动判定：全部合格 → "合格"；任一超标 → "不合格"

≥2 个浓度点 + ≥2 个 .D 文件夹时自动切换为多标签页模式（每个文件夹+浓度点一个 tab）。

4.8 参考规则：自编号命名规则

B/C 类型（储备液 / 应用液）

场景格式示例
单源{源编号去掉日期}-{浓度}-{YYYYMMDD}CK-CG-1-100.00-20260609
多源混合{主前缀}-{数量}{类型}-{浓度}-{YYYYMMDD}CK-CG-4TSCA-50.00-20260609
  • 主前缀：从所有源溶液自编号中取出现最多的 CK-XX 两段前缀
  • 有效源数量：考虑多组分来源，非简单数行数
  • 类型字段：多源混合时必填，未填则标红提示，自编号中显示 XX 占位

D 类型（工作液）— 浓度范围格式

场景格式示例
单源{源编号}-[{最低}-{最高}]-{YYYYMMDD}CK-CG-1-[5.00-100.00]-20260609
单源 + 基体…-{YYYYMMDD}-{基体}CK-CG-1-[5.00-100.00]-20260609-水
多源混合{主前缀}-{数量}{类型}-[range]-{date}CK-CG-4TSCA-[0.50-50.00]-20260609
多源 + 基体…-[range]-{date}-{基体}CK-CG-4TSCA-[0.50-50.00]-20260609-水
多源未填类型…-{数量}XX-[range]-{date}CK-CG-4XX-[0.50-50.00]-20260609
浓度范围计算：对每个稀释点取所有源组分的平均浓度，取所有稀释点的最小值和最大值组成 [min-max]。自编号默认自动生成，手动修改后切换为手动模式。

4.11.3 合并导出

A-B：g / % 类型自动合并为一份 Word，其余逐条导出。

BC-BCD（工作液 D）：导出时自动查找同日、同操作人的已有记录 → 弹窗让用户选择：

  • 「合并导出」 → 勾选记录与当前记录合并为一份 Word
  • 「单独导出」 → 仅导出当前记录
  • 关闭弹窗 → 取消

九、注意事项汇总 important

  1. 路径配置：使用前确认 Excel 和证书路径已正确配置，运行账号需有共享盘读写权限
  2. Excel 格式：推荐 .xlsx（.xls 兼容但可能有部分问题）
  3. 会话有效期：24 小时，每天首次使用需重新登录
  4. 偶氮类工作液：有效期仅 1 天，当天使用当天配制
  5. 短寿命 CAS 号：储备液有效期仅 14 天（TDI、HDI、MDI 等）
  6. 有效期上限：自动计算的有效期不会超过源标准品本身的有效期
  7. 多源混合类型必填：否则自编号出现 XX 占位符
  8. 权限限制：只能编辑/删除自己的记录，已审核记录不可编辑
  9. 合并导出前核对：确认候选列表中的记录属于同一项目，避免误合并
  10. 模板文件：请勿修改 word_templates/ 下的文件名
  11. FCM 模式：系统根据 Excel 数据自动切换，无需手动操作
  12. 基体后缀：开启基体模式后自编号和导出文档中会体现基体信息，确保输入准确
  13. 标签打印：打印前先在预览弹窗确认编号和浓度无误；打印服务需 npm start 运行
  14. 标液核查：必须选恰好 2 条 D 型记录；.D 文件夹需含 epatemp.txt

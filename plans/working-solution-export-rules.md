# 工作液配置记录导出规则（RF10-10）

## 概述

工作液（SOLUTION_TYPE_D）导出统一使用 **RF10-10 标准溶液配制记录（稀释）.docx** 模板，
通过 `/api/lims/export_bbcd_docx` 后端接口生成。所有稀释点生成 **1个** docx 文件。

## 模板列与 payload 字段映射

| 模板列 | payload 字段 | 说明 |
|---------|------------|------|
| 母体标液 | originalConcentration | 源浓度（i=0 取源编号，i>0 取前点结果） |
| 取量 | receivedQuantity | 移取体积 |
| 溶剂 | medium | 稀释介质 |
| 稀释至,ml | volume | 定容体积 |
| 浓度 | configurationConcentration | 计算结果浓度 |
| 编号 | resultCode | 自编号 |
| 配制日期 | configure_date | 配制日期 |
| 有效期 | validity_date | 有效期 |

---

## 场景一：单源（1个储备液 B → N个稀释点）

**示例**：B-3015 配 5 个稀释点

| 列 | 规则 |
|---|---|
| 母体标液 | 只显示浓度数值，不显示名称 |
| 取量 | 每行独立 |
| 溶剂/稀释至/配制日期/有效期 | 每行独立，永不合并 |
| 浓度 | 每行独立，`concValue × qty / vol` |
| 编号 | 每行独立，`baseCode-[浓度]-日期`，不合并 |

- 每行 = 1个稀释点，共 N 行
- 编号列合并判定：相邻行浓度不同，不会触发合并

---

## 场景二：单源混合型（1个混合源 C → N个稀释点）

**示例**：C-3743（= B-3388 + B-3387 + B-3386 + B-3385）配 5 个稀释点

| 列 | 规则 |
|---|---|
| 母体标液 | 只显示浓度数值。第1行取源编号浓度（如100.00），后续行取前一行结果浓度 |
| 取量 | 每行独立 |
| 溶剂/稀释至/配制日期/有效期 | 每行独立，不合并 |
| 浓度 | 各组分结果浓度的**均值** `mean(组分conc × qty / vol)` |
| 编号 | 每行独立，`baseCode-[均值浓度]-日期`，不合并 |

- 每行 = 1个稀释点，共 N 行
- 逐级链：第N点的源浓度 = 第N-1点的结果均值浓度
- 母液浓度提取：`i===0` 从源编号 `parts[-2]` 提取；`i>0` 取 `chainConcs[i-1]`

---

## 场景三：多源（多个储备液 B → N个稀释点）

**示例**：B-3015 + B-3016 配 5 个稀释点

| 列 | 规则 |
|---|---|
| 母体标液 | 第1个稀释点：每行显示**名称+浓度**（两行文本）。后续逐级链：只显示浓度 |
| 取量 | 每行独立 |
| 溶剂/稀释至/配制日期/有效期 | 第1个稀释点内多个源行**合并**，逐级链不合并 |
| 浓度 | 第1个稀释点内多个源行**合并**，逐级链不合并 |
| 编号 | 第1个稀释点内多个源行**合并**，逐级链不合并 |

- 第1个稀释点：每个源一行（共 M 行，M = 源数量）
- 逐级链（第2~N点）：每点一行（共 N-1 行）
- 总行数 = M + (N - 1)
- 合并条件：仅 `dilutionIdx` 相同的相邻行才合并

---

## 场景四：多源含混合型（C + B → N个稀释点）

**示例**：C-3743（4组分）+ B-3015 配 5 个稀释点

| 列 | 规则 |
|---|---|
| 母体标液 | 第1个稀释点：每行显示名称+浓度（C行取源编号浓度，B行取源编号浓度）。后续逐级链：只显示浓度 |
| 取量 | 每行独立 |
| 溶剂/稀释至/配制日期/有效期 | 同场景三，第1点内合并，链点不合并 |
| 浓度 | C行用组分均值浓度，B行用自身浓度。第1点内合并，链点不合并 |
| 编号 | 同规则，第1点内合并，链点不合并 |

- 第1个稀释点：每个源一行（C一行 + B一行 = 2行）
- 逐级链：每点一行（用第1点的均值结果浓度作为源）
- 总行数 = 2 + (N - 1)

## 通用规则

### 母液浓度来源

| 稀释点 | 单源（B/C） | 多源第1点 | 多源逐级链 |
|--------|------------|----------|-----------|
| `i === 0` | 源编号提取 `parts[-2]` | 各源自编号提取 | — |
| `i > 0` | `chainConcs[i-1]` | — | `chainConcs[i-1]` |

### 编号格式

```
baseCode-[结果浓度]-日期
```

`baseCode` 中 `[x-y]` 范围段替换为实际结果浓度。

### 逐级稀释（默认开启）

每个稀释点的源浓度 = 前一个稀释点的结果浓度。
- 单源：`chainConcs[i] = concValue × qty / vol`
- 多组分：`chainConcs[i] = mean(组分conc) × qty / vol`（使用组分均值计算链）
- 逐级链：`chainConcs[i] = chainConcs[i-1] × qty / vol`

### 表头（文档第一行）

- 标准物质名称：多源时所有源名称用 `；` 分隔换行显示，最后一行带 `；`
- 编号：多源时所有源编号用 `；` 分隔换行显示，最后一行带 `；`
- 浓度：单源时显示值，多源时显示"见下表"

### 合并逻辑

```
merge_cols = {2, 3, 4, 5, 6, 7}  （多源时）
merge_cols = {4, 5}               （单源时，实际因浓度不同不会触发）
```

合并条件：`tc_idx in merge_cols && val == prev_val && dilutionIdx == prev_dilutionIdx`

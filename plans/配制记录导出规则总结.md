# 配制记录导出规则总结文档

## 一、总览

系统有三种配制记录导出场景，分别对应不同的模板、接口和页面入口：

| 导出场景 | 页面标签 | 模板 | 后端接口 |
|---------|---------|------|---------|
| **储备液配制**（A→B） | 工作液标签（solExport） | RF10-09 / RF10-10 | `/api/lims/export_docx` |
| **应用液/储备液稀释**（B→C） | B-BCD标签（bbcdExport，非D） | RF10-10 | `/api/lims/export_bbcd_docx` |
| **工作液配制**（B/C→D） | B-BCD标签（bbcdExport，D） | RF10-10 | `/api/lims/export_bbcd_docx` |

---

## 二、储备液配制导出（A→B）

### 2.1 入口与分组

- 前端函数：`solExport()`
- 按领用单位和浓度单位自动分组：
  - **g/% 类型**（领用单位为 g，或浓度单位含 %）→ 合并导出为 1 个 docx
  - **其余类型**（领用单位为 mL 等）→ 逐条单独导出

### 2.2 模板选择

| 领用单位 | 模板 |
|---------|------|
| `g`（称量） | RF10-09 标准溶液配制记录(1).docx |
| `mL` 等（量取） | RF10-10 标准溶液配制记录（稀释）(1).docx |

### 2.3 浓度计算公式

```
百分比纯度：浓度 = (纯度值 / 100) × 领用量 × 10^6 / 定容体积
绝对纯度：  浓度 = 纯度值 × 领用量 / 定容体积
```

**示例**：纯度 99.5%，称取 0.1000g，定容至 100mL → 9950 μg/mL

### 2.4 合并导出逻辑

多条 g/% 类型记录合并为 1 个 docx，每条记录一页（页间分页符）。
- 所有记录共用同一个 RF10-09 模板
- 第一条记录的页眉页脚设置保留到文档末尾
- 文件名：`N条_配制记录_合并.docx`

### 2.5 RF10-09 表格字段映射（g 类型）

| 表格位置 | 填充内容 |
|---------|---------|
| 第1行-标准物质名称 | 溶液名称 |
| 第1行-编号 | 受控编号（customNum） |
| 第2行-纯度 | `纯度值(%)` |
| 第2行-设备 | 设备名称 |
| 第3行-操作描述 | `称取{取量}g标准品，用{溶剂}定容至{定容体积}mL容量瓶中，保存于{储存条件}` |
| 第4行-计算公式 | `X=（{取量}g*{纯度}%/{定容体积}mL）*10^6={结果浓度}μg/mL` |
| 第5行-编号 | 溶液编号（solutionCode） |
| 第6行-有效期 | 有效期 |
| 第8行-配制日期 | 配制日期 |

### 2.6 RF10-10 表格字段映射（mL 类型）

| 表格位置 | 填充内容 |
|---------|---------|
| 第2行-标准物质名称 | 溶液名称 |
| 第2行-编号 | 受控编号 |
| 第2行-纯度 | 纯度数值 |
| 第2行-浓度单位 | 纯度单位 |
| 第5行-母体标液 | 纯度数值 |
| 第5行-取量 | 领用量 |
| 第5行-溶剂 | 溶剂 |
| 第5行-稀释至 | 定容体积 |
| 第5行-浓度 | 计算浓度 |
| 第5行-编号 | 溶液编号 |
| 第5行-配制日期 | 配制日期 |
| 第5行-有效期 | 有效期 |

### 2.7 环境信息填充（两种模板通用）

模板第二段文字中的环境字段通过下划线占位符填入：
- 温度 → 第3个 run，居中+下划线
- 湿度 → 第10个 run，居中+下划线，后缀 `%`
- 储存条件 → 第13个 run，加下划线

## 三、应用液/储备液稀释导出（B→C）

### 3.1 入口

- 前端函数：`bbcdExport()` → `bbcdBuildExportPayload()`
- 触发条件：溶液类型不为 `SOLUTION_TYPE_D`

### 3.2 源分组逻辑

扫描配置表源溶液行，按多组分关系分组：
- 单组分源：每组1行
- 多组分源（`isComponent=true`）：同一个 `componentIdx` 系列归为一组

### 3.3 浓度计算

```
单组分：结果浓度 = 源浓度 × 取量 / 定容体积
多组分：各组分别计算 → 拼接为 "组分名:浓度;" 格式
```

### 3.4 表头填充规则

| 表头位置 | 内容 |
|---------|------|
| 标准物质名称 | 溶液名称（`bbcdSolutionName`） |
| 编号 | 所有源的 `solutionCode` 用 `；\n` 连接，末尾加 `；` |
| 浓度列标题 | `浓度({浓度单位})` |
| 源浓度 | 单源显示具体值，多源显示"见下表" |

### 3.5 数据行字段

每行对应一个源组：

| 字段 | 取值 |
|------|------|
| 母体标液（两行文本） | 第1行=源名称，第2行=源浓度 |
| 取量 | 该源的移取体积 |
| 溶剂 | 稀释介质 |
| 稀释至 | 定容体积 |
| 浓度 | 计算结果浓度 |
| 编号 | `配置编号\n溶液编码` |
| 配制日期 | 配制日期 |
| 有效期 | 有效期 |

### 3.6 单元格合并规则

| 场景 | 合并列 |
|------|--------|
| 所有 B→C | {2, 3, 4, 5, 6, 7}（溶剂、稀释至、浓度、编号、配制日期、有效期） |

合并条件：列在合并集中 + 当前行值 == 上一行值。

## 四、工作液配制导出（B/C→D）

### 4.1 入口

- 前端函数：`bbcdExport()` → `bbcdBuildWorkingSolutionExportPayload()`
- 触发条件：溶液类型为 `SOLUTION_TYPE_D`
- 始终生成 **1个** docx 文件

### 4.2 四种场景

#### 场景一：单源（1个B → N个稀释点）
- 每行 = 1个稀释点，共 N 行
- 母体标液只显示浓度数值
- 每行独立，不合并

#### 场景二：单源混合型（1个C含多组分 → N个稀释点）
- 每行 = 1个稀释点，共 N 行
- 浓度 = 各组分浓度的均值
- 逐级链：第 N 点源浓度 = 第 N-1 点结果均值浓度

#### 场景三：多源（多个B → N个稀释点）
- 第1个稀释点：每个源一行（M 行）
- 逐级链（第2~N点）：每点一行（N-1 行）
- 总行数 = M + (N - 1)
- 第1点内多源行合并 {溶剂、稀释至、浓度、编号、配制日期、有效期}
- 母体标液：第1点每行显示"名称+浓度"两行文本，逐级链只显示浓度

#### 场景四：多源含混合型（C + B → N个稀释点）
- 与场景三类似
- C 行浓度使用组分均值，B 行使用自身浓度
- 总行数 = 源数量 + (N - 1)

### 4.3 浓度计算（逐级稀释链）

```
第0点（首点）：chainConcs[0] = 源均值浓度 × 取量 / 定容体积
第i点（逐级链，i>0）：chainConcs[i] = chainConcs[i-1] × 取量 / 定容体积
```

优先使用用户手动修改的浓度值（`_userEdited` 标记）。

### 4.4 编号格式

```
baseCode-[结果浓度]-日期
```
- `baseCode` 中 `[x-y]` 范围段替换为实际结果浓度
- 多组分时取均值浓度

### 4.5 母液浓度来源

| 稀释点 | 单源（B/C） | 多源第1点 | 多源逐级链 |
|--------|------------|----------|-----------|
| `i === 0` | 从源编号提取浓度 `parts[-2]` | 各源自编号提取 | — |
| `i > 0` | `chainConcs[i-1]` | — | `chainConcs[i-1]` |

### 4.6 表头填充规则

| 表头位置 | 内容 |
|---------|------|
| 标准物质名称 | 多源时所有源名称用 `；\n` 连接，末尾加 `；`；单源时用源名称 |
| 编号 | 多源时所有源编号用 `；\n` 连接，末尾加 `；` |
| 浓度 | 单源显示具体值，多源显示"见下表" |

### 4.7 单元格合并规则

| 场景 | 合并列 |
|------|--------|
| 多源 + 第1稀释点内 | {2, 3, 4, 5, 6, 7}（溶剂→有效期） |
| 多源 + 逐级链 | 不合并（每点一行） |
| 单源 | {4, 5}（浓度、编号），实际因浓度不同通常不触发 |

合并条件：列在合并集中 + `dilutionIdx` 相同 + 值相同。

## 五、D 类合并导出（B/C 段溯源合并）

### 5.1 合并候选识别

扫描配置表源溶液行，满足以下**全部**条件为合并候选：

| 条件 | 说明 |
|------|------|
| `configureOrder` 以 `B-` 或 `C-` 开头 | 排除 A 类和 D 类 |
| 浓度单位不是 `%` | 排除百分比浓度的源 |
| 多组分只取第一行 | `isComponent=true` 且 `componentIdx=0` |
| 同一 `configureOrder` 去重 | 避免重复 |

### 5.2 合并弹窗触发条件

| 条件 | 说明 |
|------|------|
| 所有候选的配置日期以 D 的日期开头 | 同一天配置 |
| 所有候选的配置人与 D 的配置人一致 | 同一人配置 |

满足 → 弹出合并确认弹窗；不满足 → 直接导出 D 单独的配制记录。

### 5.3 溯源链（D→C→B→A）

沿 `originalCode` 字段递归向上追溯，**同一配置人 + 同一配置日期**范围内追到最顶层：

```
D → C → B → A（同人同日全链路）→ 表头取 A 的信息
         ↘ 停止（B 不同日/不同人）→ 表头取 C 的信息
```

- `originalCode` 可逗号分隔表示多源（如 `"B-3405,B-3406,B-3407"`）
- 溯源结果收集名称、编号、浓度的去重列表

### 5.4 取量反算公式

当无法直接获取取量时，从 C1V1 = C2V2 反算：

```
取量 = 结果浓度 × 定容体积 / 源浓度
```

当计算值 > 定容体积时不显示。

### 5.5 数据行排列

```
[B/C 行]   is_bc=true   dilutionIdx=负数   ← 合并候选的配制记录
────────── BC 与 D 段之间不合并 ──────────
[D 行 1]   is_bc=false  dilutionIdx=0      ← 第 1 个稀释点
[D 行 2]   is_bc=false  dilutionIdx=1      ← 第 2 个稀释点（逐级链）
...
```

BC 段与 D 段之间不发生垂直合并。

### 5.6 编号浓度修正

B/C 行的 `solutionCode`（格式 `CK-CG-{编号}-{浓度}-{日期}`）浓度部分需替换为该行实际结果浓度：

```
CK-CG-2025102-1.00-20260519 → CK-CG-2025102-0.01-20260519
```

### 5.7 浓度单位解析

LIMS 的 `concentrationUnitName` 存的是体积单位（如 `mL`），浓度单位从 `concentration` 字段解析：

```
"0.01(mg/L)"  → mg/L（括号内）
"1000μg/mL"   → μg/mL（数字后文本）
默认           → μg/mL
```

## 六、LIMS API 溯源规则

### 6.1 链路结构

| 层级 | 表 | 关键字段 |
|------|-----|---------|
| A（标准品） | `consumableReceive` | `controlledNo`, `certNo` |
| B/C/D（溶液） | `dtSolutionConfigure` | `originalCode`, `configureOrder`, `solutionCode` |

- 通过 `originalCode` 链接到父级（如 D 的 `originalCode="C-3797"`）
- `originalCode` 可逗号分隔多源

### 6.2 关键 API

| 接口 | 用途 | 注意 |
|------|------|------|
| `selectBySCId?id=数字ID` | 获取单条记录详情 | 只接受数字 ID |
| `getSolutionAdata?type=SOLUTION_TYPE_B` | 列表查询 | 必须传 type 参数 |

### 6.3 configureOrder 前缀与 type 映射

| 前缀 | type 参数 |
|------|----------|
| `B-` | `SOLUTION_TYPE_B` |
| `C-` | `SOLUTION_TYPE_C` |
| `D-` | `SOLUTION_TYPE_D` |

### 6.4 字段含义

| 字段 | 含义 | 注意 |
|------|------|------|
| `originalCode` | 父级的 `configureOrder` | 可逗号分隔多源 |
| `configureOrder` | 配置编号 | 前缀表示类型 |
| `solutionCode` | 溶液编码 `CK-CG-{编号}-{浓度}-{日期}` | 表头编号取此字段 |
| `controlledNo` | 受控编号/证书号 | 不是溶液编码 |
| `concentration` | **配置后**的结果浓度（如 `0.01(mg/L)`） | 不是源浓度 |
| `concentrationCount` | `父名:结果浓度(单位)` | 冒号后是结果浓度 |
| `constantVolume` | 定容体积（mL） | |
| `saveDetailList` | **始终为 null** | 不可用，需从其他字段重建 |

## 七、通用规则

### 7.1 环境信息

所有模板导出时都填充以下环境信息到文档第二段：
- 温度 → 下划线居中
- 湿度 → 下划线居中 + `%`
- 储存条件 → 下划线

### 7.2 表格行数自适应

当数据行数超过模板预置行数时，自动复制最后一行模板行并插入备注行之前。

### 7.3 文件命名

| 场景 | 文件名 |
|------|--------|
| 合并导出（A→B） | `N条_配制记录_合并.docx` |
| 单条导出（A→B） | `配制记录_{序号}.docx` |
| B→C 导出 | `{solutionCode}_配制记录.docx` |
| B/C→D 导出 | `{solutionCode}_配制记录.docx` |

### 7.4 数据验证

导出前检查：
- A→B：必须已填写领用量、定容体积、计算浓度
- B→C：定容体积 > 0
- B/C→D：至少有一个有效稀释点（取量和体积均 > 0）
